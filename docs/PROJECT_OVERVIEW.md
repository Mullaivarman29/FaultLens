
# FAULTLENS
## Distributed System Reliability & Failure Analysis Platform

### Overview
FaultLens is a microservice monitoring prototype designed to
simulate service failures, identify potential downstream impact,
and provide reliability analytics.

### Core Features
- Service health monitoring
- Failure simulation and recovery
- Incident management
- Service dependency intelligence
- Rule-based root cause analysis
- Reliability analytics dashboard
- Automatic dashboard refresh

### Technology Stack
- Python
- FastAPI
- JavaScript
- HTML5
- CSS3
- REST APIs

### Architecture
Frontend Dashboard → FastAPI Backend → Service Simulation
                                      → Incident Management
                                      → Dependency Analysis
                                      → Reliability Analytics

### Project Scope
This is an educational prototype using simulated service
metrics and in-memory data. It does not yet implement
production telemetry or persistent storage.
